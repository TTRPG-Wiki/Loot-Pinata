Loot Pinata

Roll D&D 5e, Pathfinder 2e, Shadowdark, OSE, or custom loot from the OBR sidebar.

Install URL

How to install

  1. Copy the install URL above.
  2. In Owlbear Rodeo, open the Extensions panel.
  3. Click "Add Extension" and paste the URL.
  4. Click the Loot Pinata icon in OBR's sidebar to roll.
