# Loot Pinata

A sidebar loot generator for [Owlbear Rodeo](https://www.owlbear.rodeo/). Click the icon, pick a system, roll treasure.

## Install

Install URL:

```
https://ttrpg-wiki.github.io/Loot-Pinata/manifest.json
```

In Owlbear Rodeo: open the Extensions panel → **Add Extension** → paste the URL. The Loot Pinata icon will appear in the OBR sidebar.

## How to use

1. Click the **Loot Pinata** icon in OBR's sidebar.
2. Pick a system from the dropdown (D&D 5e, Pathfinder 2e, Shadowdark, OSE, or Custom).
3. Pick a CR / level / tier / treasure type appropriate to the encounter.
4. Hit **🎲 Roll Loot!** — coins, gems, jewelry, and magic items appear in the panel.

If you happen to have a token selected when you open the panel, the extension will remember the last roll on that token and warn you if it's already been looted.

## Supported systems

- **D&D 5e** — DMG Individual Treasure tables by CR (0–30)
- **Pathfinder 2e** — Treasure-by-Level (levels 1–20)
- **Shadowdark** — Tier-based treasure with items from the Core Rulebook
- **OSE / B/X** — All 21 classic Treasure Types (A through V)
- **Custom** — Upload your own JSON loot tables, or browse community submissions

## Custom & community tables

In the Custom tab you can:

- **Upload** your own JSON loot table from disk (stored in your browser's localStorage).
- **Browse community** to one-click install tables contributed by other GMs.
- **Download example** to get a template you can edit.
- **View format spec** to see all the fields a custom table can use.

Want to share a table with everyone? See [CONTRIBUTING.md](CONTRIBUTING.md) — PR a JSON file into `public/community-tables/` and it'll show up in every install under "Browse community" once merged.
